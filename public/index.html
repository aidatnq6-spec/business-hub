💾 Backup & Restore dữ liệu
Xuất file JSON để lưu trữ · Import để khôi phục
📥 Xuất Backup
Tải dữ liệu trên Firestore gồm deals, thu chi, công nợ, công việc, căn hộ, khách CKS, IT tùy chỉnh và trạng thái thu tiền thuê dưới dạng JSON.
📤 Khôi phục từ Backup
Chọn file JSON backup để khôi phục. Bản ghi trùng ID sẽ được cập nhật, bản ghi mới được thêm; các bản ghi khác được giữ lại. Hãy export backup trước khi import.
📋 Lịch sử backup (lưu trong trình duyệt)
💡 Gợi ý: Backup mỗi tuần 1 lần và lưu vào Google Drive. File JSON nhỏ (~50KB), có thể lưu nhiều phiên bản. Đặt tên rõ ngày tháng để dễ tìm.
